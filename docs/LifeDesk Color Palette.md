# LifeDesk Color Layout

Trustworthy, intelligent, calm, and modern — not overly corporate and not too "health app."

## Primary Brand Colors

| Color          | Hex       | Use                                        |
| -------------- | --------- | ------------------------------------------ |
| Deep Navy      | `#172B4D` | Primary brand, headings, navigation        |
| Life Teal      | `#16A6A0` | Main CTA buttons, active states, key features |
| Warm Amber     | `#F4B942` | Alerts, highlights, important reminders    |
| Off White      | `#F7F9FC` | Main app background                        |
| Charcoal       | `#263238` | Body text                                  |
| Soft Gray      | `#E6EBF2` | Borders, cards, dividers                   |

## Interface application

- **App background:** `#F7F9FC` — soft off-white
- **Top navigation:** `#172B4D` — deep navy
- **Primary buttons:** `#16A6A0` — Life Teal (Add Reminder, Add Bill, Add Asset)
- **Secondary buttons:** white background, deep navy text, teal border
- **Important alerts:** `#F4B942` — amber ("Vehicle insurance expires in 12 days.")
- **Urgent alerts:** restrained red `#E05252` ("Generator service is overdue.")
- **Success:** `#2E9D68` ("Insurance renewed successfully.")

## Dashboard color structure

- **Header (LIFEDESK):** Deep Navy
- **Needs Attention:** Amber-accented card
- **Upcoming:** White card, teal icon
- **Home / Documents:** White cards

## Module accent colors

| Module        | Color    | Hex       |
| ------------- | -------- | --------- |
| Home          | Teal     | `#16A6A0` |
| Transport     | Blue     | `#3978B8` |
| Money & Bills | Green    | `#2E9D68` |
| Documents     | Purple   | `#7A65B1` |
| Family        | Coral    | `#E8786A` |
| Maintenance   | Amber    | `#F4B942` |
| Assets & Warranties | Navy | `#172B4D` |

Keeps the app scannable without every screen becoming a different color scheme.

## Brand ratio

- **60%** Off-white / neutral
- **20%** Deep Navy
- **15%** Teal
- **5%** Amber + status colors

## Overall direction

Deep Navy + Teal + Amber + lots of white space.
"Trust this app with the things that keep your life running."

Works equally for mobile app, web dashboard, logo, marketing materials, and African-market expansion.
